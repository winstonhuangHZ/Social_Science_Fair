\section{Experiment Details}
This experiment involves cleaning, filtering, and performing sentiment detection on Reddit post data from 9 different subreddits.
\begin{itemize}
    \item \textbf{Input Data Status:} Clean
    \item \textbf{Total Posts Scanned:} 362,063 posts
    \item \textbf{Total Posts Filtered:} 184,045 posts (50.8\% of the total)
    \item \textbf{Total Time Elapsed for Filtering:} 22 minutes 46 seconds (average of 151.82 seconds per file)
\end{itemize}

\subsection{LLM Sentiment Detection Environment}
The environment and hardware configurations for the LLM sentiment detection pipeline are specified below:
\begin{itemize}
    \item \textbf{Model Name:} Qwen/Qwen2.5-14B-Instruct-GPTQ-Int4 (14 Billion Params)
    \item \textbf{Framework:} vLLM Boosted
    \item \textbf{GPU:} 1x NVIDIA RTX 4090
    \item \textbf{GPU Memory:} 24GB
    \item \textbf{GPU Memory Utilization:} 92\%
    \item \textbf{Max Model Length:} 2048 tokens
    \item \textbf{CUDA Version:} 12.1
    \item \textbf{CPU:} 16x vCPU Intel(R) Xeon(R) Platinum 8358P CPU @ 2.60GHz
    \item \textbf{System RAM:} 90GB
    \item \textbf{Concurrent Concurrency:} 128
\end{itemize}
